Figure 1

What happens to one recording

Nobody has to press anything. Once a date folder lands on the NAS, the bench analyses it and the results show up on the Dashboard.

Figure 2

Where the data goes

The raw recordings are only ever read. Big temporary files go to a fast local disk and are deleted when the job ends. Results are written to one place and copied from there.

Figure 3

What the bench is made of

One program on labtower1 serves the web page and runs everything behind it. The lab's analysis pipeline, MEA-Analysis, is run as is and never changed.

Source: the bench's code and its live settings on labtower1, 27 Nov 2026. Analyses currently run on labtower1; the lab cluster is one switch away in Settings.
